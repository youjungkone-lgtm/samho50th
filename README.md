`index.html`을 텍스트 편집기로 열면 상단 스크립트에 아래처럼 차량 데이터가 한 블록으로 모여 있습니다.

```
/* ══════════ 차량 편성 데이터 (수정 시 이 DATA 블록만 손대면 됩니다) ══════════
   buses 키: '1'~'9' = 버스 1~9호차, 'S1'~'S3' = 스타렉스 1~3호
   name=표시명 · captain=차장 성함 · phone=연락처(없으면 '') · capTitle=차장 직함 */
const DATA = {...};
```

- **차장 연락처 변경**: 해당 차량의 `phone` 값만 고치면 됩니다.
- **탑승 인원 이동**: `people` 배열에서 해당 성도의 `"b"` 값(예: `"7"` → `"S2"`)만 고치면 됩니다.
- 일정·안내 문구는 HTML 본문에서 직접 수정 가능합니다.
- 수정 후 같은 방식(Deploys 탭)으로 재배포하면 즉시 반영됩니다.

function doSearch(){
  const raw = document.getElementById('q').value.trim();
  const box = document.getElementById('results');
  if(!raw){ box.innerHTML=''; return; }
  const k = norm(raw);
  const hits = P.filter(p => norm(p.n).includes(k));
  if(!hits.length){
    box.innerHTML = `<div class="card" style="text-align:center">
      <div style="font-size:38px">🍂</div>
      <div style="font-weight:800;font-size:17px;margin:6px 0 2px">‘${raw}’ 이름을 찾을 수 없습니다</div>
      <div style="font-size:14.5px;color:var(--sub)">이름 전체(성 포함)로 다시 입력해 보세요.<br>그래도 없으면 행사준비위원회에 문의해 주세요.</div>
    </div>`;
    return;
  }
  const dups = hits.length > 1;
  box.innerHTML = `<p class="hint" style="font-weight:800;color:var(--deep)">${hits.length}명 검색됨</p>` + hits.map(p=>personCard(p, dups)).join('');
}
document.getElementById('q').addEventListener('keydown', e=>{ if(e.key==='Enter') doSearch(); });
